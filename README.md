
Assets

"/assets/sprites" = Sprites do jogo
"/assets/sounds" = Arquivos de audio e efeitos sonoros


Configurações via properties

~~~ properties
engine.assets.sprites.path={NOVO_PATH_SPRITES} 
engine.assets.sounds.path={NOVO_PATH_SOUNDS}
~~~

~~~ properties
app.name={NOME_DO_JOGO}
app.width={LARGURA_DA_TELA}
app.height={ALTURA_DA_TELA}
~~~
